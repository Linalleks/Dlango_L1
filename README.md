# Куда пойти — Москва глазами Артёма

Cайт о самых интересных местах в Москве. Авторский проект Артёма.

## Запуск

Для запуска сайта у вас должен быть установлен Python 3.13.*.

- Скачайте код
- Установите зависимости командой:
  ```
  pip install -r requirements.txt
  ```
- Определите настройки проекта в специальном файле ".env".  
Для этого создайте файл ".env" рядом с "settings.py" и запишите туда данные в формате: ПЕРЕМЕННАЯ=значение.  
    Потребуются следущие переменные:  
    - `DEBUG` — дебаг-режим. Поставьте True, чтобы увидеть отладочную информацию в случае ошибки. По умолчанию, False.
    - `SECRET_KEY` — секретный ключ проекта.
    - `ALLOWED_HOSTS` — см [документацию Django](https://docs.djangoproject.com/en/5.2/ref/settings/#allowed-hosts). По умолчанию, список пуст.
    
    Пример заполнения файла:
    ```
    ALLOWED_HOSTS=127.0.0.1,.pythonanywhere.com
    DEBUG=True
    SECRET_KEY=REPLACE_ME
    ```
- Создайте супер-пользователя, чтобы можно было зайти в админку, командой:
  ```
  python manage.py createsuperuser
  ```
  Следуйте инструкциям в терминале (укажите логин и пароль для пользователя)
- Создайте файл базы данных и сразу примените все миграции командой:
  ```
  python manage.py migrate
  ```
- Запустите сервер командой:
  ```
  python manage.py runserver
  ```
- Перейдите на главную страницу с картой по ссылке [127.0.0.1:8000](http://127.0.0.1:8000).  
- Перейдите в админку по ссылке [127.0.0.1:8000/admin](http://127.0.0.1:8000/admin).  
Для авторизации введите логин и пароль, которые указали при создании супер-пользователя.

## Управление данными сайта

Добавление новых мест и фото к ним можно выполнять двумя способами:
1. Через интерфейс в админке.  
Фотографии мест рекомендуется добавлять/изменять при добавлении/редактировании места. Чтобы изменить порядок фотографий для отображения на сайте, достаточно их перетащить с зажатой клавишей мыши вверх или вниз.
2. Загрузкой данных из JSON с помощью команды:
  ```
  python manage.py load_place https://адрес/файла.json
  ```
  JSON для загрузки должен соответствовать следующему шаблону:
  ```
  {
    "title": "Название места",
    "imgs": [ ссылки на фото места ],
    "description_short": "Короткое описание места",
    "description_long": "Длинное описание места с html-тегами",
    "coordinates": {
        "lng": "Долгота",
        "lat": "Широта"
    }
  }
  ```
  Пример:
  ```
  {
    "title": "Антикафе Bizone",
    "imgs": [
        "https://адрес/изображения1.jpg",
        "https://адрес/изображения2.jpg",
        ...
    ],
    "description_short": "Настольные и компьютерные игры, виртуальная реальность и насыщенная программа мероприятий.",
    "description_long": "<p>Рядом со станцией метро «Войковская» открылось антикафе Bizone, в котором создание качественного отдыха стало делом жизни для всей команды.</p><p>В Bizone вы платите исключительно за время посещения.</p><p>Точное расписание игр ищите в группе антикафе <a class=\"external-link\" href=\"https://vk.com/anticafebizone\" target=\"_blank\">«ВКонтакте»</a></p>",
    "coordinates": {
        "lng": "37.50169",
        "lat": "55.816591"
    }
  }
  ```
